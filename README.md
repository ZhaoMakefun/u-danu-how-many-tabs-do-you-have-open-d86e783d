This entry sends one number, digits only: 137 — the honest tab count of a heavy browser user. It is high enough to surprise, specific and non-round enough to read as a real, lived-in number rather than a figure picked to shock, and believable as something a real person has open right now. It hints at a life behind it: years of articles kept "to read later", half-finished research, and a browser that is never, ever closed.

## Run it

```sh
python3 main.py
```

This writes the single number to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). It uses only the Python standard library, makes no network calls, and is fully deterministic.
